# AI 使用声明

本实验（实验二：React 项目实战与 Zustand 状态管理）使用 AI（豆包）情况如下：

## 使用范围

1. **概念解释**：React 官方文档对应章节（组件、props、state、Hook 规则、状态提升等）的机制讲解；
2. **报错翻译与排错**：Vite 端口占用、依赖安装、key 警告、`posts.map is not a function` 等报错的分析；
3. **代码对照与核对**：井字棋、useLocalStorage、Zustand store、TanStack Query 写法与官方/指导书代码逐段核对；
4. **整段代码审查**：按实验要求让 AI 生成一版组件代码后，进行五检查点审查与整改，过程留痕在 `ai-review.md`。

## 我的工作

- 所有代码均在本机运行并截图验证；
- 井字棋、博客组件、状态管理为手写为主，AI 未直接生成整段功能代码；
- ai-review.md 中列出的问题均为真实发现并已整改，运行行为变化经复现确认。
